Guía semanal

Límite: este paquete es informativo y sintético. No contiene el runtime de analistas y no puede ejecutar un corte privado.

1. Fuentes antes que métricas

  1. Abre la plantilla vacía. Contiene las 22 tablas canónicas.
  2. Consulta el diccionario para conocer tipo, unidad y significado de cada campo.
  3. Captura hechos observados sin inventar valores. Vacío no significa cero; una celda desconocida permanece vacía.
  4. Guarda el archivo lleno como copia privada fuera del ZIP. Nunca sobrescribas el ejemplo o la plantilla.

2. Política separada

El archivo REVIEW es una plantilla no aprobada. El archivo SYNTHETIC_EXAMPLE sólo sirve para el ejemplo sintético. La política no forma parte de las 22 tablas y no concede autoridad para actuar.

3. Demo pública

Abre la demo pública o lee el recorrido resuelto. Ambos muestran datos sintéticos y pueden revisarse sin conexión.

EstadoQué significaSiguiente paso
WAITINGFalta respuesta o recibo verificable.Esperar o entregar la evidencia exacta.
BLOCKEDUna entrada, hash o contrato no es válido.Corregir la causa indicada y crear un corte nuevo.
REVIEWEl resultado puede leerse, pero la política no está aprobada.Revisión humana; no ejecutar decisiones.

4. Entrega a análisis

Entrega por el canal acordado la copia privada y la política aplicable. El analista ejecuta el flujo desde su repositorio local; los cortes y recibos privados permanecen en .local/. El kit no hace upload, no sync, no modifica sistemas externos y no realiza ejecución comercial.
