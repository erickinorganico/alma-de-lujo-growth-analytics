`scripts/package_release_v1.py` accepts `--ref v1.0.0|COMMIT --output .local/releases/Alma_OS_v1.0.0.zip --checksum ... --acceptance ...`. It must build from a fresh `git archive` of that exact ref, call the Phase 4 public-kit builder in the archive, require the exact committed Phase 5 workbook hashes/receipts, and normalize ZIP order, paths, permissions and timestamps. It writes an inner `acceptance-summary.json` that excludes the outer ZIP hash, then writes external checksum and acceptance sidecars after the ZIP exists.

The external acceptance sidecar is intentionally not a tracked input to the tagged commit: it records the final ZIP hash without creating a self-reference. It is a release asset alongside the ZIP and `.sha256`. The tracked `client/v1/acceptance-summary.json` contains gate identities, receipt hashes, limitations and EXT states but no private paths, task response bodies or outer archive hash.

## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Tagged Git tree → release builder | Only reviewed committed public inputs may enter the deterministic package. |
| ZIP central directory → extracted filesystem | Malicious paths, duplicates, links or decompression behavior must be rejected before writes. |
| Local release assets → GitHub release | Tag, commit, account, uploaded bytes and readback hashes must remain identical. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05-11 | Tampering | ZIP/member/checksum | mitigate | D-07/D-08 explicit allowlist, normalized deterministic build, per-member/outer hashes, second rebuild and downloaded-asset recheck. |
| T-05-12 | Information disclosure | Public release content | mitigate | Inspect text and binary surfaces; reject private paths/cuts/native bodies/registers, secrets and PII-like content. |
| T-05-13 | Elevation of privilege | ZIP extraction | mitigate | Validate traversal, absolute/device/case-fold paths, symlinks, counts/sizes/ratios before extracting into a new directory. |
