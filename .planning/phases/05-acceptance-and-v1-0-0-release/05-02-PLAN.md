<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Generated XLSX → desktop Excel → committed bytes | Excel may recalculate or mutate workbook bytes; final hashes and cached values require independent verification. |
| Git commit → archive/disposable environment | Untracked files and local interpreters must not become hidden release dependencies. |
| Repository → GitHub Actions | Remote jobs run dependency and artifact code with a token and must use least privilege/no secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-05-06 | Tampering | Workbook formulas/cache/receipt | mitigate | D-04/D-05 independent oracle, fresh Excel engine record, exact post-save hashes and mutation tests. |
| T-05-07 | Information disclosure | Workbook metadata/hidden content/PDF | mitigate | Inspect complete XLSX surfaces and exported pages; reject private metadata, links, comments and hidden values. |
| T-05-08 | Repudiation | Visual inspection | mitigate | Per-page dispositions bind inspector/runtime, timestamp and exact workbook/PDF hashes; missing pages block. |
| T-05-09 | Spoofing | Clean archive/CI provenance | mitigate | Resolve commit SHA, use `git archive`, record actual Actions run/job IDs and validate artifact receipt hashes. |
| T-05-10 | Elevation of privilege | GitHub Actions token | mitigate | D-06 `contents: read`, no secrets, project wrapper for CLI and no write/deploy step in verification jobs. |
| T-05-SC | Tampering | Pinned dependency install | mitigate | Install only committed `requirements-client.txt`; do not add packages or change pins without a new legitimacy audit. |
</threat_model>
