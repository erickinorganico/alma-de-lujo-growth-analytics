## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phase 1/2 artifacts → cycle builder | Files are read-only inputs but can be stale, replaced, malformed or linked elsewhere. |
| Cycle builder → private filesystem | Generated report/task bytes and hashes must be atomic, path-confined and immutable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | Upstream cut/bundle identity | mitigate | Call upstream verify APIs, compare stable cut IDs and hash every consumed artifact before task creation. |
| T-03-02 | Tampering | `current-cut.json`, requests, state/events | mitigate | Canonical SHA-256, atomic writes, hash-chained events, exact-byte revalidation and changed-input refusal. |
| T-03-03 | Repudiation | Task-bundle creation | mitigate | Record contract version, source hashes, request inventory and event timestamp in the private journal. |
| T-03-04 | Information disclosure | CLI output and generated files | mitigate | Confine runtime output to `.local`, print only hashes/status, and test blank/synthetic data publicly. |
| T-03-05 | Denial of service | Oversized/recursive inputs | mitigate | Use the verified bounded upstream inventories, reject links/traversal and cap role/evidence/request sizes. |
| T-03-06 | Elevation of privilege | Request write scope | mitigate | Contract permits only response/query-trace files and declares all external execution prohibited. |
| T-03-SC | Tampering | Package installation | mitigate | No package install is allowed; use Python stdlib and existing pinned project dependencies only. |
</threat_model>
