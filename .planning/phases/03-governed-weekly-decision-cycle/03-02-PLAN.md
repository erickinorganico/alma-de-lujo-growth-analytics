<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native task → response bridge | Model output and claimed references are untrusted until schema, value, hash and authority validation passes. |
| Parent runtime → dispatch receipt | Receipt is a parent attestation that must contain actual runtime metadata and exact response hash. |
| Accepted analysts → reviewer | Reviewer sees frozen evidence and accepted outputs; no party may replace either after dispatch. |
| Private cycle → public acceptance receipt | Only synthetic metadata/hashes/status may cross; response prose and private paths remain local. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Spoofing | Native role/model/agent identity | mitigate | Enforce explicit role-family matrix, native provider/mode, real task ID shape and reviewer identity distinct from all analysts. |
| T-03-08 | Tampering | Response, receipt, accepted analysis, reviewer request | mitigate | Exact canonical hashes, immutable files, revalidation at every transition and reviewer request bound to all accepted digests. |
| T-03-09 | Repudiation | Live task execution | mitigate | Record parent-runtime ID/model/effort/timestamps/hashes and state the receipt's attestation scope without overstating it. |
| T-03-10 | Information disclosure | Native evidence and public receipt | mitigate | Private `.local` storage, role evidence allowlists, no prose/values/paths in public acceptance and privacy audit. |
| T-03-11 | Denial of service | Oversized response or repeated submission | mitigate | Bound strings/arrays, one acceptance per role, locking and idempotent exact replay. |
| T-03-12 | Elevation of privilege | Recommendation or task write authority | mitigate | Reject extra/mutation/action fields; require approval and `execution: PROHIBITED`; verify upstream artifacts unchanged. |
| T-03-SC | Tampering | Package installation | mitigate | No package installation; use the existing native runtime and project environment only. |
</threat_model>
