<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Terminal packet → owner event | Packet is advisory; owner choice and identity token are untrusted inputs until contract validation. |
| Prior register → next cut | History and anchor can be changed independently; both must agree before carry-forward. |
| Later cut → closure | Cited evidence must resolve in exact verified bytes and satisfy a typed predicate. |
| Canonical register → CSV | Spreadsheet projection/import can introduce formula execution or silent state changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-13 | Spoofing | Owner attestation | mitigate | Allowlisted non-PII owner roles, explicit local-attestation scope and no claim of cryptographic authentication. |
| T-03-14 | Tampering | Event ledger, anchor and carry-forward | mitigate | Canonical append-only hash chain, independent expected anchor and next-cut binding. |
| T-03-15 | Repudiation | Decision/status/extension/closure | mitigate | Immutable event type, actor role, UTC timestamp, source/packet/cut hashes and prior event hash. |
| T-03-16 | Information disclosure | Private decisions and CLI/CSV | mitigate | `.local` confinement, bounded projections, no PII owner fields and hash/status-only CLI output. |
| T-03-17 | Denial of service | Event/CSV import | mitigate | Exact columns, bounded rows/fields, duplicate rejection, locks and atomic append. |
| T-03-18 | Elevation of privilege | CSV formulas or false closure | mitigate | Reject formula prefixes, strict transitions, exact evidence pointers and deterministic closure predicates. |
| T-03-SC | Tampering | Package installation | mitigate | No package install is allowed; use Python stdlib and existing project helpers only. |
</threat_model>
