## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Private source/workbook → weekly run | Untrusted source rows cross into immutable analytical artifacts only after Phase 1–2 validation. |
| Native task response → reviewed packet | Model output and parent receipt cross the Phase 3 exact-reference and distinct-review gates. |
| Private run/public generator → ZIP | Explicit allowlisted blank/synthetic files cross to public distribution. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T-04-08 | Spoofing | Native stage receipt | mitigate | Use Phase 3 actual task ID/model/response digest validator; request preparation alone remains WAITING. |
| T-04-09 | Tampering | Cut/register continuation | mitigate | Verify immutable source/report and prior register anchors; reject overwrite, changed hashes and reviewer identity reuse. |
| T-04-10 | Information disclosure | Client ZIP | mitigate | Build from allowlist/fresh generated public outputs, audit all ZIP members plus embedded workbook/HTML surfaces, reject private paths and content. |
| T-04-11 | Elevation of privilege | Weekly command/guide | mitigate | Never execute external business actions or auto-register owner decisions; state the human boundary in guide and index. |
| T-04-SC | Tampering | Dependency install | accept | Reuse pinned workbook libraries and standard library; no package install is part of this plan. |
</threat_model>
