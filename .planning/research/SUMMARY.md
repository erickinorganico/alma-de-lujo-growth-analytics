# Research Summary

The recommended final path is a unified private weekly operating cycle alongside the immutable v0.2 demonstration. It should reuse the current Decimal workbook validator, native response schemas, hash discipline and offline packaging while adding the missing canonical operating sources and closure flow.

The highest-value scope is: versioned intake; cost/purchase/receipt/obligation/cash reconciliation; product/variant learning; quality and fit evidence; budget/drop controls; exception queue; native analyst plus independent review; decision carry-forward; and a polished analyst/client package. A React/Supabase transactional application remains outside the governing product boundary.

The milestone is complete only when two distinct synthetic weekly cuts execute end to end, a reviewed decision carries from week one to week two, tampering and double counting fail closed, all prior tests remain green, Excel artifacts receive fresh engine evidence if formulas change, and the extracted v1.0.0 package works offline.
