# Run one operating-cycle-v1 native analysis

This procedure applies only to verified Phase 1 operating cuts and Phase 2 mart bundles. It does not use the historical `python -m alma workspace` or `python -m alma process` commands. Keep all full reports, responses, traces, receipts, and packets under ignored `.local/` paths. Never send real customer data to a public artifact.

1. Prepare a cycle with `.venv\Scripts\python.exe scripts/run_weekly_cycle.py start --source-pack PACK --output-root .local/weekly-cycles` (or `--workspace CUT --mart-bundle BUNDLE` for an already verified boundary). The source-pack route defaults to `.local/` and `.local/operating-marts`; explicit disposable roots are accepted in tests. Confirm `WAITING_ANALYSTS`, the current-cut hash and six request paths with `status --cycle CYCLE`.
2. Read `agents/native-cycle-v1.roles.json`, `contracts/weekly-cycle-v1.schema.json`, and the exact `tasks/ROLE.request.json` before dispatch. The request contains the role's aggregate metric rows, coverage and lineage. `synthetic_business_data` comes from the verified cut; a PRIVATE cut is never called synthetic. Do not infer orders, customers or observed zero from aggregate or missing evidence.
3. Dispatch the six independent native Codex tasks in bounded batches: Terra for `merchandiser` and `finance_analyst`, Luna for `commerce_analyst` and `returns_analyst`, Sol for `growth_analyst` and `market_researcher`. Each task receives its exact request path, the schema and its role contract. It may write only `tasks/ROLE.response.json` and `tasks/ROLE.query-trace.json` and may not execute a business action.
4. Each analyst must run at least one registered read-only metric lookup from the request, for example `.venv\Scripts\python.exe scripts/run_weekly_cycle.py query --request REQUEST --reconciliation-id ID`. Use the returned exact `/metric_rows/N` pointers in a canonical query trace with question, parameters, result_refs and row_count. Every response needs two evidenced facts, explicit unknowns, hypotheses and challenges; observation values must equal the referenced JSON types and values. A recommendation requires primary metric, guardrail, population, window, closure rule, owner approval and `execution: PROHIBITED`.
5. The parent runtime, after actual task completion, records its canonical `/root/...` agent ID, exact native model, effort, UTC start/end, and response/query-trace hashes. It prepares a parent dispatch attestation with `provider: native-codex`, `recorded_by: parent-runtime`, `mode: live`, and the full `parent_validation_scope`. Run `record --cycle CYCLE --role ROLE --response RESPONSE --query-trace TRACE --receipt-fields FIELDS` and then `submit --cycle CYCLE --role ROLE --response RESPONSE --query-trace TRACE --receipt RECEIPT`. The bridge validates local contracts and hashes; a schema-valid fixture is not evidence that a model ran, and the receipt is not a provider signature.
6. After every analyst is accepted, run `resume --cycle CYCLE` and recheck status. The bridge verifies the unchanged upstream cuts, current-cut bytes, requests and accepted artifacts. Only after all six validate does it emit `tasks/evidence_reviewer.request.json`, binding every analyst response, trace and dispatch digest.
7. Dispatch a separate native Astra `evidence_reviewer` task. Its task ID must differ from every analyst ID. The reviewer reads the frozen evidence and all accepted analyses, challenges denominator, coverage, timing and alternative explanations, and writes only its response and trace. Record and submit with the same commands. A `BLOCKED` verdict cannot become owner-ready.
8. Read the advisory terminal result using `packet --cycle CYCLE`; `status` and `resume` must revalidate all hashes. `READY_FOR_OWNER` asks the owner to decide and does not authorize payment, purchase, refund, pricing, publishing, messaging or any other external execution.
9. For the one synthetic acceptance run, export only the exact public metadata/hash/status allowlist to `evidence/v1/native-cycle-acceptance.json`; verify with `verify-acceptance --receipt evidence/v1/native-cycle-acceptance.json`, then run `.venv\Scripts\python.exe scripts/audit_release.py`. Keep response prose, metric values, queries, source paths and real data private.
