# Alma de Lujo · Growth & Business Analytics

Reproducible local-first analytics and Growth portfolio project for a Mexican sportswear brand, including multicolor Pilates socks as an unverified hero-product hypothesis.

This repository is under active implementation. Data is explicitly synthetic. Planned delivery: Python/SQLite pipeline, validated metrics, exportable tables, generated analytical reports and plots, evidence-backed decision packets and experiment playbooks. No frontend, server or transactional application is in scope.

Run locally with Python 3.11+ (standard library only): `python -m alma demo`. Final clean-install and verification instructions will be included with the validated release.

Intended public repository: `erickinorganico/alma-de-lujo-growth-analytics`. No real customer data, credentials, paid API, account connections, purchases or automated external business actions.

Original project code: MIT license. External sources are linked with provenance and limitations, not copied as proprietary datasets.
